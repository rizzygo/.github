# Como contribuir com a Rizzygo

Este guia vale para todo repositório da Rizzygo que não tenha o próprio CONTRIBUTING.

1. **Abra uma issue** para contar o erro ou a ideia. Uma issue é um tópico de conversa no GitHub. Pergunta básica é bem-vinda.
2. **Mande um pull request** se já sabe o que mudar. Pull request é uma proposta de alteração. Alguém revisa a proposta antes de ela entrar no repositório.
3. **Escreva os commits em português**, no formato Conventional Commits: `fix: corrige o link da lição de Linux`.
4. **Rode a verificação do repositório** antes de enviar. O README de cada repositório diz qual comando usar.

Nunca contribuiu com um projeto aberto? Comece por uma issue no [ako](https://github.com/rizzygo/ako).
